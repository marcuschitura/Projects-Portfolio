Engineering Profile

I've always been fascinated by how small systems create big change — how a control loop can stabilise a vehicle, how a filter cleans a biological signal, or how a well-routed PCB makes hardware reliable.

My focus is on control systems, embedded design, PCB layout and RF engineering. This portfolio is a reflection of that journey, showcasing projects where I learned to think critically, design precisely, and build things that actually work.

Microphone Array Source Localization

Dual microphone array for parking distance estimation, allows driver to know if they are too close to an object. It features MIC E1 PCB electret microphones with a LM318N dual preamplifier with a 1.67 V bias voltage. Fed to a DUal Regular Simultaneous Mode setup STM32G474RE microcontroller for synchronized ADC sampling.
