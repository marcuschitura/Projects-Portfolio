Wearable EMG Device for Prosthetic Control

Project Overview

This project involved the design and implementation of a wearable electromyography (EMG) device for capturing muscle activity data to support gesture identification for a bionic hand used by amputees. The design follows guidelines from the Surface Electromyography for the Non-Invasive Assessment of Muscles (SENIAM) project and established biomedical standards.

Biomedical Engineering Signal Processing LTspice Arduino Control Systems
  • Duration: 12 weeks
  • Role: Lead Designer & Engineer
  • Category: Biomedical Electronics & Signal Processing

Problem Statement

Traditional EMG systems for prosthetic control are often limited by their complexity, lack of portability, and susceptibility to motion artifacts. This project aimed to develop a wearable solution that addresses these limitations while maintaining accurate signal acquisition.

Key Challenges

  • Designing a system with high input impedance to interface with dry electrodes
  • Implementing effective noise rejection for motion artifacts and electrical interference
  • Creating a compact, wearable form factor suitable for daily use
  • Ensuring compatibility with prosthetic control systems

Methodology & Approach

The design employed a single-channel EMG configuration with differential signal acquisition for improved noise immunity. The system architecture included:

Technical Implementation

  • Ag-AgCl dry electrodes following SENIAM placement standards
  • 3 op-amp instrumentation amplifier with gain of 11 and CMRR of 100.827 dB
  • Fourth-order Butterworth bandpass filter (20-500 Hz)
  • Precision rectifier and envelope detector for signal conditioning
  • Arduino Nano for signal processing with 1200 Hz sampling rate
  • Bluetooth module for wireless data transmission

Results & Analysis

Key Achievement: The system successfully captured EMG signals within the target bandwidth of 2.99Hz to 468.89 Hz, with a fast response time of 0.8 seconds to reach steady state. The design proved cost-effective at R1665.80 while meeting key performance criteria for wearable prosthetic applications.

Performance Metrics

  • Input impedance: 10^12 Ω (OPA2604 op-amps)
  • Common Mode Rejection Ratio: 100.827 dB
  • Bandwidth: 2.99Hz - 468.89 Hz
  • Sampling rate: 1200 Hz (meeting Nyquist criteria)
  • Response time: 0.8 seconds to steady state

Edge Computation in 5G IAB Networks

Project Overview

This project focused on optimizing task offloading in 5G Integrated Access and Backhaul (IAB) networks to minimize latency and energy consumption at the network edge.

5G Networks Edge Computing Optimization MATLAB
  • Duration: 12 weeks
  • Role: Network Optimization Engineer
  • Category: Communication Systems

Problem Statement

5G networks with IAB architecture face challenges in efficiently distributing computational tasks between edge devices and central servers, leading to increased latency and energy consumption.

Key Challenges

  • Developing an efficient task offloading algorithm for IAB networks
  • Balancing computational load between edge and central resources
  • Minimizing both latency and energy consumption

Methodology & Approach

Developed a multi-objective optimization algorithm that considers network conditions, computational requirements, and energy constraints to determine optimal task offloading strategies.

Technical Implementation

  • Modeled 5G IAB network architecture in MATLAB
  • Implemented a genetic algorithm for task offloading optimization
  • Evaluated performance under varying network conditions

Results & Analysis

Key Achievement: The optimization algorithm reduced average task completion latency by 32% and energy consumption by 28% compared to traditional offloading approaches.

Performance Metrics

  • 32% reduction in average task completion latency
  • 28% reduction in energy consumption
  • Improved network resource utilization by 45%

Footbridge Active Vibration Control

Project Overview

This project involved designing and implementing a Linear Quadratic Regulator (LQR) controller to actively suppress vibrations in footbridge structures, improving safety and comfort.

Control Systems LQR Controller Vibration Analysis Simulink
  • Duration: 8 weeks
  • Role: Control Systems Engineer
  • Category: Structural Control

Problem Statement

Footbridges can experience excessive vibrations due to pedestrian loading, wind, and other environmental factors, leading to discomfort and potential structural issues.

Key Challenges

  • Modeling footbridge dynamics accurately
  • Designing a controller that can handle multiple vibration modes
  • Implementing the controller in a real-time system

Methodology & Approach

Developed a state-space model of the footbridge and designed an LQR controller to minimize vibrations while considering control effort constraints.

Technical Implementation

  • Created a finite element model of the footbridge structure
  • Designed an LQR controller with optimal weighting matrices
  • Simulated the controlled system in Simulink
  • Implemented the controller on a real-time embedded system

Results & Analysis

Key Achievement: The LQR controller successfully reduced vibration amplitudes by up to 85% across multiple vibration modes, significantly improving pedestrian comfort.

Performance Metrics

  • 85% reduction in vibration amplitudes
  • Effective control across first three vibration modes
  • Real-time implementation with minimal computational overhead

Application of Full State Feedback Controller on a Non-Linear Braking System for EV

Project Overview

This project involved the implementation of a full state linearisation control law, aimed at controlling the slip coefficient ensuring optimal braking in different road conditions.

Simulink Non-Linear Control Control Systems
  • Duration: 10 weeks
  • Role: Control System Designer
  • Category: Power Electronics & Systems Design

Problem Statement

Traditional braking systems struggle to maintain optimal slip ratios across varying road conditions, leading to reduced braking efficiency and safety concerns.

Key Challenges

  • Simulation of system dynamics for non-linear system.
  • Mathematical formulation of non-linear feedback linearisation law.
  • Achieving optimal braking and meeting performance criteria for optimal braking coefficient.

Methodology & Approach

Designed a line-interactive UPS topology with automatic voltage regulation, battery backup, and fast switching between mains and battery power.

Technical Implementation

  • Simulated system dynamics in Simulink.
  • Develop system dynamics and apply Lie derivatives to find the linearised feedback control law.
  • Use pole placement to control the performance of the car model to ensure performance criteria is met.

Results & Analysis

Key Achievement: The simulated model showed that the full state feedback controller was able to maintain the slip coefficient within optimal braking limits across varying road conditions, enhancing braking performance and safety. A 3 second breaking time with a braking distance of 41.69 m was achieved for a vehicle at 100 km/hr on a high friction road surface meeting performance criteria based on the Tesla Model S regenerative braking system which received a 5 star NCAP safety rating. A optimal 0.20 friction coefficient was maintained across varying road conditions.

Performance Metrics

  • Achieved a 3 second braking time for a car at 100.91 km/hr
  • Achieved a 41.69 m braking distance
  • Achieved a 0.20 slip ratio coefficient
