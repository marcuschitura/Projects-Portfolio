Edge Computation in 5G IAB Networks

Project Overview

This research project focused on optimising task offloading strategies in 5G Integrated Access and Backhaul (IAB) networks to minimize latency and energy consumption for edge computing applications.

Problem Statement

Existing computation offloading methods are ineffective for 5G mmWave IAB networks because they assume stable links and simple topologies. This project designed a new offloading algorithm to solve this gap, enabling efficient, low-latency task execution in next-generation networks.

Methodology

  • Designed a directed acyclic graph network topology with 8 IAB nodes collocated with a MEC server.
  • Implemented a Breadth First Search routing selection policy for load balancing.
  • Developed a slice-specific multi-objective optimisation algorithm.
  • Benchmarked against convex game theory and single/joint objective optimisation algorithms.

Results

  • Energy Efficiency: 89.3%
  • Offloading Rate: 43.9%
  • Latency: Minimum of 4.4 ms, average of 11.5 ms across 1531 URLLC tasks.
  • Throughput: Network throughput of 3.25 Gbps, peaking at 5.42 Gbps.

Footbridge Active Vibration Control

Project Overview

This project involved designing and simulating an active vibration control system for pedestrian footbridges using Linear Quadratic Regulator (LQR) control theory.

Methodology

The solution was approached iteratively: single degree of freedom PID, then LQR in state space, and finally a multi-degree of freedom model paired with a total sum penalty multi-actuator LQR control law.

Results

  • Vibration Reduction: 35.7% to 72.6% across modes 2 through 6.
  • Settling Time: 75% faster.
  • Control Effort: Maintained within practical implementation limits.

EV Braking System Controller

Project Overview

Implementation of a full state linearisation control law aimed at controlling the slip coefficient, ensuring optimal braking in different road conditions.

Methodology

  • Simulated system dynamics in Simulink.
  • Applied Lie derivatives to find the linearised feedback control law.
  • Used pole placement to control the performance of the car model.

Results

  • Braking Time: 3 seconds for a car at 100.91 km/hr.
  • Braking Distance: 41.69 m.
  • Slip Ratio Coefficient: 0.20 (optimal).

Wearable EMG Device

Project Overview

Design and implementation of a wearable electromyography (EMG) device for capturing muscle activity data to support gesture identification for a bionic hand used by amputees.

Methodology

  • Ag-AgCl dry electrodes following SENIAM placement standards.
  • 3 op-amp instrumentation amplifier with gain of 11 and CMRR of 100.827 dB.
  • Fourth-order Butterworth bandpass filter (20-500 Hz).
  • Arduino Nano with 1200 Hz sampling rate.

Results

  • Bandwidth: 2.99Hz - 468.89 Hz.
  • Response Time: 0.8 seconds to steady state.
  • Cost: R1665.80.

Audio Controlled Remote Toy Car

Project Overview

Designed and implemented a microcontroller-free remote-controlled toy car operated through audio signals using DTMF tone detection and pure analog circuitry.

Methodology

  • Four LM567 tone detectors set to 1937Hz, 3635Hz, 4564Hz, and 7133Hz.
  • Dual-tone system requiring pairs of tones for each command.
  • Custom-built NOR gates convert tone detector outputs to motor control signals.

Results

  • Track Time: 7.38 minutes.
  • Control Distance: ~1 meter.
  • Immunity: Full immunity via dual-tone system.

Automated Pallet Sorting System

Project Overview

Implemented an automated pallet sorting system using Siemens S7-1200 PLC with ladder logic programming for deterministic, fault-tolerant control.

Methodology

  • Memory bits store decisions instead of relying on real-time sensor states.
  • Shift-left instructions for logical pallet tracking.
  • Interlocks centralize logic operation safety.

Results

  • Successfully implemented memory-based decision storage and shift-bit tracking.
  • Production counting in a deterministic control system with emergency stop.
