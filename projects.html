Edge Computation in 5G IAB Networks

Project Overview

This research project focused on optimising task offloading strategies in 5G Integrated Access and Backhaul (IAB) networks to minimize latency and energy consumption for edge computing applications.

NS-3 C++ MATLAB Network Simulation 5G Networks Multi-Objective Optimisation Algorithm
  • Duration: 8 weeks
  • Role: Researcher & Developer
  • Category: Networking & Edge Computing

Problem Statement

Existing computation offloading methods are ineffective for 5G mmWave IAB networks because they assume stable links and simple topologies. They fail to dynamically adapt to the real-world challenges of volatile mmWave signals, the energy cost of multi-hop routing, and congestion in a shared wireless backhaul. This project designed a new offloading algorithm to solve this gap, enabling efficient, low-latency, and energy-conscious task execution in next-generation networks.

Key Challenges

  • Energy efficiency in multi-hop network topologies
  • Conflicting quality of service requirements across the different 5G network slices
  • Computational complexity for real time decision making
  • Designing an algorithm complex enough to be effective yet simple enough for polynomial-time execution in a dynamic network

Methodology & Approach

Developed a hierarchical edge computing framework integrated with 5G IAB network topology, implementing dynamic task allocation algorithms based on real-time network conditions.

Technical Implementation

  • Designed a directed acyclic graph network topology with 8 IAB nodes collocated with a MEC server at the gNB base station, with a a dynamic propagation model using 3GPP UMi Canyon Modelling.
  • Implemented a Breadth First Search routing selection policy to ensure efficiency load balancing across the network.
  • Developed a slice specific multi-objective optimisation algorithm.
  • Benchmarked the performance of the proposed algorithm against other optimisation algorithms such as convex game theory optimisation,single objective optimisation and joint objective optimisation.

Results & Analysis

Key Achievement: Collected results indicate that the proposed multi-objective algorithm maintains a balanced trade-off between energy efficiency (89.3 %) and offloading rate (43.9 %) while achieving minimal latency, full deadline adherence, and 100 % reliability across multiple network slices.

Performance Metrics

  • Achieved a minimum latency of 4.4 ms with a average of 11.5 ms across 1531 URLLC tasks.
  • Achieved a network throughput of 3.25 Gbps peaking at 5.42 Gbps for the URLLC network slice indicating latency improvements are met without compromising data rate performance.
  • Achieved a minimum latency of 4.1 ms and a average of 153.4 ms across 2813 eMMB tasks.
  • The eMMB network slice attained a data rate of 3.2 Gbps peaking at 5.54 Gbps, showing sustainability of eMMB services.
  • Energy efficiency improvements of up to 89.3% were observed while maintaining an offloading rate of 43.9% across the 5044 tasks produced in the simulation environment.

Footbridge Active Vibration Control

Project Overview

This project involved designing and simulating an active vibration control system for pedestrian footbridges using Linear Quadratic Regulator (LQR) control theory to suppress structural vibrations induced by human movement and environmental factors.

MATLAB Simulink Control Systems LQR Control Structural Dynamics
  • Duration: 8 weeks
  • Role: Control System Designer
  • Category: Control Systems & Structural Engineering

Problem Statement

Pedestrian footbridges often experience excessive vibrations due to human-induced loads and environmental factors, leading to discomfort for users and potential structural integrity issues over time.

Key Challenges

  • Modelling a MDOF footbridge that is susceptible lateral excitations
  • Designing a controller robust to varying excitation frequencies
  • Minimizing control effort while maximizing vibration suppression within servicebility limits
  • Accounting for real-world implementation constraints

Methodology & Approach

The solution was approached iteratively, with the initial implementation of a single degree of freedom PID controller for proof of concept. This was developed into a single degree of freedom LQR controller in state space to compare the performance of the two proposed control paths. A multi-degree of freedom model of the footbridge susceptible to lateral excitations was proposed, this was paired with a proposed total sum penalty multi-actuator LQR control law aimed at providing vibration supression at multiple frequencies.

Technical Implementation

  • Created detailed mathematical model of bridge dynamics
  • Implemented LQR controller with optimised weighting matrices
  • Simulated system response to various excitation patterns
  • Analyzed controller performance under different scenarios

Results & Analysis

Key Achievement: The controller reduced structural vibrations from the second to the sixth modes of vibration, with improvements in lateral excitation mitigation ranging from 35.7% to 72.6%, meeting serviceability criteria and practical implementation limits.

Performance Metrics

  • Vibration amplitude reduction: 35.7% - 72.6% across modes
  • Settling time improvement: 75% faster
  • Control effort: Within practical implementation limits
  • Robustness: Maintained performance across frequency range

Project Overview

This project involved the implementation of a full state linearisation control law, aimed at controlling the slip coefficient ensuring optimal braking in different road conditions.

Simulink Non-Linear Control Control Systems
  • Duration: 10 weeks
  • Role: Control System Designer
  • Category: Power Electronics & Systems Design

Problem Statement

Traditional braking systems struggle to maintain optimal slip ratios across varying road conditions, leading to reduced braking efficiency and safety concerns.

Key Challenges

  • Simulation of system dynamics for non-linear system.
  • Mathematical formulation of non-linear feedback linearisation law.
  • Achieving optimal braking and meeting performance criteria for optimal braking coefficient.

Methodology & Approach

Designed a line-interactive UPS topology with automatic voltage regulation, battery backup, and fast switching between mains and battery power.

Technical Implementation

  • Simulated system dynamics in Simulink.
  • Develop system dynamics and apply Lie derivatives to find the linearised feedback control law.
  • Use pole placement to control the performance of the car model to ensure performance criteria is met.

Performance Metrics

  • Achieved a 3 second braking time for a car at 100.91 km/hr
  • Achieved a 41.69 m braking distance

Wearable EMG Device for Prosthetic Control

Project Overview

This project involved the design and implementation of a wearable electromyography (EMG) device for capturing muscle activity data to support gesture identification for a bionic hand used by amputees. The design follows guidelines from the Surface Electromyography for the Non-Invasive Assessment of Muscles (SENIAM) project and established biomedical standards.

LTspice Arduino Signal Processing Biomedical Engineering Control Systems
  • Duration: 6 weeks
  • Role: Lead Designer & Engineer
  • Category: Biomedical Electronics & Signal Processing

Problem Statement

Traditional EMG systems for prosthetic control are often limited by their complexity, lack of portability, and susceptibility to motion artifacts. This project aimed to develop a wearable solution that addresses these limitations while maintaining accurate signal acquisition.

Key Challenges

  • Designing a system with high input impedance to interface with dry electrodes
  • Implementing effective noise rejection for motion artifacts and electrical interference
  • Creating a compact, wearable form factor suitable for daily use
  • Ensuring compatibility with prosthetic control systems

Methodology & Approach

The design employed a single-channel EMG configuration with differential signal acquisition for improved noise immunity. The system architecture included:

Technical Implementation

  • Ag-AgCl dry electrodes following SENIAM placement standards
  • 3 op-amp instrumentation amplifier with gain of 11 and CMRR of 100.827 dB
  • Fourth-order Butterworth bandpass filter (20-500 Hz)
  • Precision rectifier and envelope detector for signal conditioning
  • Arduino Nano for signal processing with 1200 Hz sampling rate
  • Bluetooth module for wireless data transmission

Results & Analysis

Key Achievement: The system successfully captured EMG signals within the target bandwidth of 2.99Hz to 468.89 Hz, with a fast response time of 0.8 seconds to reach steady state. The design proved cost-effective at R1665.80 while meeting key performance criteria for wearable prosthetic applications.

Performance Metrics

  • Input impedance: 10^12 Ω (OPA2604 op-amps)
  • Common Mode Rejection Ratio: 100.827 dB
  • Bandwidth: 2.99Hz - 468.89 Hz
  • Sampling rate: 1200 Hz (meeting Nyquist criteria)
  • Response time: 0.8 seconds to steady state

Hand Motion Measurement System for Stroke Rehabilitation

Project Overview

This project involved the design, construction, and testing of a displacement measurement system to monitor hand motion capability for stroke rehabilitation. The system uses a Hall effect sensor to detect hand displacement and classifies movement as "adequate" or "insufficient" based on clinical thresholds.

Arduino Uno SS495A Hall Sensor Signal Processing I2C LCD Display Biomedical Measurement Embedded Systems
  • Duration: 8-10 weeks
  • Role: Lead Designer & System Integrator
  • Category: Biomedical Engineering & Measurement Systems
  • Team Size: 2 members

Problem Statement

Stroke rehabilitation requires accurate monitoring of motor recovery progress, particularly in hand function. Existing solutions are often complex and expensive. This project aimed to create a cost-effective displacement measurement system that clinicians could use to characterize rehabilitation progress for stroke patients.

Key Challenges

  • Designing within sensor limitations (SS495A Hall effect sensor)
  • Achieving accurate displacement measurement within 10-40mm range
  • Implementing non-linearity correction for sensor output
  • Creating a clinically relevant classification system (adequate vs insufficient movement)
  • Meeting target error of 5% with limited components

Methodology & Approach

The system was designed using Bentley's measurement system model, with SS495A Hall effect sensor as the sensing element, Arduino Uno for signal processing, and I2C LCD display for data presentation.

Technical Implementation

  • Sensing Element: SS495A Hall effect sensor detecting magnetic field changes from hand-mounted magnet
  • Signal Processing: Arduino Uno performing ADC conversion and non-linearity correction using equation: y = 0.075x + 1.77
  • Movement Classification: Threshold-based system: ≥20mm = "ADQ" (Adequate), <20mm = "INS" (Insufficient)
  • Display: I2C LCD module showing real-time displacement and classification
  • Power Supply: 5V power bank using Duracell Plus Alkaline Battery

Results & Analysis

Key Achievement: The system successfully measured hand displacement within 10-40mm range with 85.83% accuracy and 181.35Hz bandwidth, providing real-time feedback for stroke rehabilitation monitoring.

Performance Metrics

  • Accuracy: 85.83% (target: 95%)
  • System Error: 14.17% (target: 5%)
  • Bandwidth: 181.35Hz
  • Sensitivity: 0.075V/mm
  • Input Range: 10-40mm displacement
  • Output Range: 2.5V - 4.84V
  • Cost: R388.40 total system cost

Error Analysis

  • Sensor error: 9%
  • Signal processing error: 3%
  • Display error: 2.17%
  • Total system error: 14.17%

Critical Analysis & Future Recommendations

The system offers low-cost, non-invasive operation with real-time feedback but is limited to one axis of motion and requires individual patient calibration.

Improvement Opportunities

  • Use more robust sensors for better accuracy
  • Implement multi-axis motion detection
  • Add wireless data transmission for remote monitoring
  • Develop more sophisticated classification algorithms
  • Reduce system error to meet 5% target

Audio Controlled Remote Toy Car

Project Overview

This project designed and implemented a microcontroller-free remote-controlled toy car operated through audio signals using DTMF tone detection. The system uses pure analog circuitry with LM567 tone detectors to decode specific audio frequencies for directional control.

LM567 Tone Detectors L298N Motor Driver MAX9814 Microphone Analog Circuit Design DTMF Signal Processing Custom NOR Gates
  • Duration: 8-10 weeks
  • Role: Team Lead & Circuit Designer
  • Category: Control Systems & Embedded Design
  • Team Size: 3 members

Problem Statement

Design a remote-controlled toy car using audio signals as control input, with immunity against interference from other teams' signals, without using any microcontrollers, and with strict power constraints (max 5V across DC motors).

Key Constraints

  • No microcontrollers allowed in design
  • Control signal limited to 20Hz-20kHz audio range
  • Maximum 10V supply for circuit, 5V across DC motors
  • No modifications to issued chassis
  • Immunity against other teams' control signals

Methodology & Approach

The solution uses LM567 tone detectors configured to detect specific audio frequencies, with dual-tone activation for interference immunity. Custom NOR gates were built to process the logic signals.

Technical Implementation

  • Tone Detection: Four LM567 tone detectors set to frequencies: 1937Hz, 3635Hz, 4564Hz, and 7133Hz
  • Dual-Tone System: Pairs of tones required for each command (e.g., 1937Hz + 3635Hz = Forward)
  • Signal Processing: Custom-built NOR gates convert tone detector outputs to motor control signals
  • Motor Control: L298N motor driver with direct interface from NOR gate outputs
  • Audio Input: MAX9814 microphone module with 2Vpp amplitude and adjustable gain
  • Control Interface: Custom mobile app for generating control tones

Results & Analysis

Key Achievement: Successfully completed the track course in 7.38 minutes with full immunity against other teams' signals, meeting all design constraints without using any microcontrollers.

Performance Metrics

  • Track Completion Time: 7.38 minutes
  • Control Distance: ~1 meter with loud speaker
  • Optimal Tone Range: 3kHz - 6kHz
  • Immunity: Full immunity achieved through dual-tone system
  • Power Supply: 5V power bank (attempted 10V but caused jittery motion)

Control Scheme

  • Forward: Tone A (1937Hz) + Tone B (3635Hz)
  • Right Turn: Tone A (1937Hz) + Tone C (4564Hz)
  • Left Turn: Tone B (3635Hz) + Tone C (4564Hz)
  • Reverse: Used instead of forward turning due to implementation constraints

Design Evolution & Challenges

The project evolved through several design iterations:

Initial Approaches (Abandoned)

  • Analog filter bank with frequency-to-voltage converters
  • FSK (Frequency Shift Keying) modulation
  • ASK (Amplitude Shift Keying) modulation

Technical Challenges Overcome

  • Microphone sensitivity: Electret mic (20mV) → KY-038 module → MAX9814 (2Vpp)
  • NOR gate inconsistency: 74LS02 IC → custom-built NOR gates
  • Speed control: XL600L DC-DC boost converter attempted but abandoned
  • High frequency harmonics: Discarded 7133Hz tone due to harmonic interference

Cost Analysis & Future Improvements

Total Cost: R930.00

  • LM567 Tone Detectors (4×): R120
  • MAX9814 Microphone (2×): R208
  • XL600L Boost Converter: R140
  • Power Banks: R470

Recommended Improvements

  • Use XE2211 IC (two logic outputs per IC) to reduce cost
  • Build custom MOSFET H-bridge instead of L298N for better efficiency
  • Implement forward turning capability
  • Increase control range with better audio amplification

Automated Pallet Sorting System

Project Overview

This project implemented an automated pallet sorting system using Siemens S7-1200 PLC programmed with ladder logic (IEC 61131-3). The system detects, classifies by height, tracks, and routes pallets using deterministic control logic with fault tolerance in the Factory I/O simulation environment.

Siemens TIA Portal Ladder Logic Factory I/O PLC Programming Industrial Automation IEC 61131-3
  • Duration: 1 week
  • Role: PLC Programmer & Systems Engineer
  • Category: Control Systems & Industrial Automation
  • Platform: Siemens S7-1200 PLC

Problem Statement

Design and implement a deterministic, fault-tolerant control system for automated pallet sorting that operates reliably in industrial environments, with proper tracking, classification, and routing logic.

Key Requirements

  • Pallet detection and entry handling
  • Height classification (low/high)
  • Position tracking through the system
  • Deterministic routing to left/right conveyors
  • Fault-tolerant emergency stop system
  • Production counting and validation

Methodology & Approach

The system was designed using memory-based decision storage rather than real-time sensor dependency, with shift-bit tracking for pallet position and deterministic control logic.

System Architecture

  • Control Logic: Ladder logic (IEC 61131-3) programmed in Siemens TIA Portal
  • Simulation Environment: Factory I/O for realistic industrial simulation
  • Memory Structure: Decision storage in memory bits for independence from sensor states
  • Tracking Method: Shift-left instructions for logical pallet tracking
  • Safety System: Emergency stop overrides all motion commands

Key Engineering Decisions

  • Memory bits store decisions instead of relying on real-time sensor states
  • Edge detection prevents repeated actions within single pallet cycles
  • Logical tracking (bit shifting) improves robustness and scalability
  • Interlocks centralize logic operation safety
  • Timer-controlled turntable rotation for consistent mechanical motion

System Logic Breakdown

Core Control Principle: The system uses stored decisions rather than real-time sensor dependency, making it deterministic and fault-tolerant.

Functional Modules

  • Start/Stop Control: Latched memory bit controls all downstream logic with emergency stop override
  • Pallet Detection: Optical and proximity sensors with debouncing logic
  • Height Classification: Low and high optical sensors with Set/Reset logic for decision storage
  • Pallet Tracking: Shift-left instruction moves bit through storage byte as pallet advances
  • Turntable Control: Timer-controlled rotation with TOTALLY ROTATED memory bit
  • Conveyor Routing: Exclusive actuation based on stored height decision and pallet position
  • Production Counting: Counters with edge case prevention for accurate tracking

Technical Implementation Details

1. Pallet Detection & Entry Handling

  • Optical sensors detect pallet presence
  • Debouncing logic prevents multiple triggers
  • Feeder and entry conveyors coordinate for smooth entry

2. Height Classification System

  • Low and high optical sensors classify each pallet
  • Classification result stored in decision memory using Set/Reset logic
  • Preserves decision even after pallet leaves sensing zone
  • Avoids scan cycle dependency

3. Pallet Tracking Implementation

  • Shift-left instruction moves bit through 8-bit storage byte
  • Each pallet advancement triggers bit shift
  • Logical tracking independent of physical sensor reliability
  • Improves system robustness

4. Turntable Control Logic

  • Timer controls turn motor for fixed duration
  • TOTALLY ROTATED memory bit set upon completion
  • Guarantees consistent mechanical motion
  • Independent of sensor noise or delays

5. Conveyor Routing System

  • Activation based on stored height decision and pallet position
  • Interlocks prevent simultaneous left/right conveyor actuation
  • Exclusive and deterministic routing
  • Memory-based rather than sensor-based decisions

6. Production Counting & Validation

  • Counters track processed pallets
  • Additional logic prevents double counting
  • Provides production feedback
  • Validates correct system behavior
